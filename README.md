# NSM SALLE — برنامج تسيير القاعات الرياضية

**ما بقى حتى واحد يتدرب بلا ما يخلص.** نظّم قاعتك فبرنامج واحد: كل منخرط يمرّر بطاقتو، الخالص يدخل والمنتهي اشتراكو الباب ما يتفتحلوش. المنخرطين، الدخول بالبطاقة، الكايس، الديون والإحصائيات.

---

## واش هو NSM SALLE؟

برنامج كمبيوتر يخدم على **ويندوز**، **بلا أنترنت**. المعلومات كاملة تبقى فالكمبيوتر تاعك، وتقدر دير **نسخة احتياطية** فأي وقت. البرنامج **بالعربية وبالفرنسية**، ومصنوع فالجزائر.

## المميزات

- **الدخول بالبطاقة RFID**: الاشتراك منتهي ولا الحصص خلصو؟ الدخول يترفض فالحين. المنخرط يمرّر بطاقة ولا تاغ.
- **المنخرطين والاشتراكات**: شهري، 3 أشهر، سنوي ولا بالحصص، مع تجديد بضغطة وحدة.
- **الكايس والمبيعات**: بيع المشروبات والمكمّلات بالقطعة، بالعلبة ولا بالغرام.
- **ديون المنخرطين**: سجّل الكريدي وتابع شكون دفع وشكون باقي عليه.
- **المدربين والسحوبات**: سجّل سحوبات كل مدرب بالتاريخ والمبلغ.
- **الإحصائيات**: الإيرادات، الحضور، الجدد والتجديدات، مع تصدير PDF.
- **حسابات الكايسي**: كل كايسي عندو حساب تاعو بصلاحيات محدودة، والأدمين يتحكم فكلش.
